먼저 스캔본을 받아 주는 공고인지 확인합니다

채용공고에서 파일 형식, 용량, 파일 수, 서명·원본 요구를 먼저 읽으세요. PDF만 받는 곳도 있고 서류별 개별 파일을 요구하는 곳도 있습니다. 온라인 발급 PDF를 이미 갖고 있다면 출력해서 다시 촬영하기보다 원래 파일을 제출할 수 있는지 확인하는 편이 선명합니다. 사진의 확장자만 .pdf로 바꾸는 것은 PDF 변환이 아닙니다.

스캔은 종이를 디지털 사본으로 만드는 작업입니다. 발급기관의 전자증명서나 진위확인 기능, 공고에서 요구한 원본을 자동으로 대체하지는 않습니다. 신분증·계약서처럼 민감한 서류는 채용처가 요구한 범위만 준비하고, 원본 내용이나 발급 표시는 임의로 고치지 마세요.

안드로이드는 Google Drive에서 PDF로 저장합니다

Google 공식 도움말의 현재 안내는 Drive 앱에서 카메라 → 촬영 → 자르기·회전 등 조정 → 필요한 페이지 추가 → 완료 → 파일명과 PDF 형식 선택 → 저장 순서입니다. 앱 버전에 따라 화면 위치나 표현은 달라질 수 있습니다. 저장 위치가 Google Drive라는 점도 확인하고, 다른 사람이 쓰는 계정이나 공용 기기의 계정에 개인 서류를 올리지 않도록 주의하세요.

자동으로 잡힌 테두리가 도장·발급번호·하단 안내를 잘라내지 않았는지 확인합니다. 사진 보정은 읽기 쉽게 하는 수준으로 사용하고, 원본의 내용이 바뀌는 편집은 하지 않습니다. 여러 장이라면 첫 장부터 촬영해 페이지 순서를 점검한 뒤 한 파일로 저장하세요.

아이폰은 파일 앱의 문서 스캔을 이용할 수 있습니다

Apple 공식 안내에 따라 파일 앱의 더 보기 → 문서 스캔을 선택하고 종이를 화면 안에 둡니다. 자동 또는 수동으로 촬영한 뒤 모서리를 조정하고 필요한 페이지를 추가합니다. 완료 후 저장할 위치를 선택하세요. 메모 앱에서도 첨부 버튼의 문서 스캔을 사용할 수 있습니다. 다만 제출 단계에서 메모 전체의 공유 링크와 실제 문서 파일을 혼동하지 않도록 저장한 파일을 다시 열어 확인합니다.

용량이 크면 흐릿해질 때까지 압축하기보다 빈 페이지 제거, 필요 이상으로 촬영한 배경 정리 등부터 살피세요. 민감한 서류를 정체가 불분명한 무료 변환 사이트에 올리는 것은 피하는 편이 좋습니다. 용량을 줄인 뒤에는 작은 숫자와 서명이 읽히는지 다시 확대합니다.

마지막으로 채용 시스템에서 첨부 파일을 미리 보거나 내려받아 페이지 수를 확인하세요. 저장 버튼과 제출 버튼이 따로 있는지도 살핍니다. 완료 화면과 접수번호를 보관하되, 공용 컴퓨터를 썼다면 내려받은 서류를 정리하고 로그아웃하세요. 이 글의 이미지는 실제 앱 화면이 아닌 설명용 그림이며, 앱 조작은 연결한 공식 도움말을 기준으로 확인할 수 있습니다.
