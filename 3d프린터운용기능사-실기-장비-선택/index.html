공식 실기는 설계 파일에서 끝나지 않습니다

Q-Net은 실기 평가 범위를 3D 모델링 소프트웨어를 이용한 제품 디자인, 슬라이싱 소프트웨어를 이용한 출력 프로그램 작성, 3D프린터 활용으로 설명합니다. 필기는 데이터 생성, 3D프린터 설정, 제품출력 및 안전관리이며 객관식 60문항·60분입니다. 실기는 3시간 작업형이고 필기·실기 각각 60점 이상이 합격 기준입니다. 현재 안내된 출제기준 적용기간은 2024~2027년입니다.

따라서 상담할 때 완성 모델 이미지 대신 수업 중 본인이 만든 출력용 데이터와 장비 설정 기록을 어떻게 확인해 주는지 물어보세요. 강사가 대신 설정한 출력물만 받는다면 어떤 판단을 본인이 연습했는지 알기 어렵습니다.

공동 장비의 숫자보다 기다리는 시간을 계산하세요

다음은 시험 규정이나 실제 학원 견적이 아닌 가상 비교입니다. 수강생 6명이 프린터 2대를 쓰고, 한 사람이 장비를 점유하는 시간이 준비·정리를 포함해 90분이라면 총 540프린터·분이 필요합니다. 두 대를 동시에 사용해도 모두 한 차례 끝내려면 최소 270분이 경과합니다. 180분 수업 한 번 안에 전원이 독립적으로 끝낼 수 있다고 가정해서는 안 됩니다. 출력 대기 중 모델링 수업을 하더라도 개인별 장비 사용 기회가 늘어나는 것은 아닙니다.

이 계산을 상담표에 적용해 장비 예약을 수업 외 시간에도 할 수 있는지, 실패 출력도 제공 횟수에서 차감하는지, 재료비에 재출력이 포함되는지 확인하세요. 출력 소요시간은 형상·재료·장비에 따라 달라지므로 90분을 실제 시험의 출력시간으로 사용하면 안 됩니다.

개인 프린터 구입은 시험장 조건 확인 뒤로 미루세요

공식 수험료는 필기 14,500원, 실기 27,000원으로 합계 41,500원입니다. 여기에 장비 구입비가 자동으로 필요한 것은 아닙니다. 시험장 장비와 지참 목록을 확인하고 교육장 대여·예약으로 부족한 부분을 먼저 산정하세요. 특정 기종이나 프로그램 버전이 전국 공통이라고 이 글에서 보장하지 않습니다.

Q-Net은 3D프린터, 필라멘트, 후가공용 칼 등을 주요 장비로, 방진마스크와 보호장갑 등을 보호구로 안내합니다. 실제 작업별 보호구와 환기·가열부 접근 지시는 교육 담당자의 안전교육 및 시험장 안내를 따르세요. 출력 후 칼 작업까지 영상만 보고 혼자 연습하는 방식은 피해야 합니다.

자주 묻는 질문

모델링 강의만 수료해도 실기 준비가 되나요?

공식 평가에는 슬라이싱을 통한 출력 프로그램 작성과 프린터 활용도 포함됩니다. 모델 파일을 실제 출력 데이터로 바꾸고 장비에서 결과를 확인하는 연습이 빠졌는지 확인하세요.

학원에 프린터가 많으면 개인 연습도 충분한가요?

수강생 수, 장비 점유시간, 수업 외 예약, 실패 시 재출력 규칙을 함께 봐야 합니다. 장비 보유 대수만으로 개인 사용 횟수를 판단할 수 없습니다.

집에서 연습하려면 시험장과 같은 프린터를 사야 하나요?

구입을 필수로 단정할 근거는 없습니다. 먼저 응시 시험장의 장비·준비물 안내를 확인하고 교육장 이용으로 확보할 수 없는 연습이 무엇인지 계산하세요.
