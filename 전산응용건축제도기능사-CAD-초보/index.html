건축도면 공부와 CAD 조작을 함께 합니다

Q-Net의 필기 안내는 건축계획 및 설계도면 작성을 객관식 60문항 60분으로 평가합니다. 실기는 전산응용건축제도실무를 약 4시간 내외의 작업형으로 안내하며 합격 기준은 60점 이상입니다. 확인 시점에 제공되는 현재 출제기준은 2026~2029년 적용 자료입니다.

공식 출제경향은 기본·계획 설계도를 현장에서 필요한 도면으로 표현하는 능력을 설명합니다. 다만 상세 페이지에 남아 있는 2024년 문제 유형 설명을 2026년 이후 시험의 새 공고로 이해하지 마세요. 현재 출제기준과 응시 회차 안내, 허용 프로그램과 제출·출력 조건을 따로 확인해야 합니다.

명령을 배우기 전에 도면의 관계를 봅니다

편집자의 제안은 도면에서 각 표시가 어떤 대상을 뜻하는지 설명하고 관련 도면끼리 관계를 확인하는 것입니다. 프로그램으로 선을 그릴 수 있어도 도면의 조건을 이해하지 못하면 결과가 달라질 수 있습니다. 먼저 현재 교재의 기본 표시와 치수를 읽고 같은 내용을 화면에서 표현하는 연습으로 연결하세요.

가상의 오류 사례로, 선 모양은 비슷하지만 위치나 표시 조건을 놓쳤다면 CAD 조작 오류와 도면 해석 오류를 구분해야 합니다. 어떤 명령을 썼는지만 기록하지 말고 무엇을 표현하려 했는지도 적습니다. 이 글은 실제 건축물의 설계·허가를 판단하는 자료가 아니며 시험 학습 결과를 법정 설계 자격으로 표현하지 않습니다.

작은 작업과 전체 작업을 나눕니다

초보자는 파일 열기, 기본 설정, 화면 이동과 자주 쓰는 조작을 짧은 작업으로 연습해 보세요. 이후 도면의 조건을 읽고 작업 순서를 정하는 전체 연습을 합니다. 모든 명령을 먼저 외운 뒤 과제에 들어가기보다 본인이 자주 틀리는 조작과 도면 조건을 함께 기록하는 편이 학습 방향을 잡기 좋습니다.

실기 연습의 프로그램과 버전은 시험장 안내에 맞춰 확인합니다. 교육기관이 사용하는 환경과 응시 환경이 다를 수 있으며 임의로 추가 도구나 외부 파일을 사용할 수 있다고 가정하지 않습니다. 연습용 프로그램은 정식 제공 경로와 이용 조건을 따르고 출처가 불명확한 설치파일이나 불법 복제를 사용하지 마세요.

공식 기본정보는 컴퓨터와 프린터를 안내합니다. 완성 화면이 정상이어도 저장 파일이나 출력 결과가 맞지 않을 수 있습니다. 연습에서는 마지막에 결과를 다시 열고 출력 조건을 확인하는 시간을 남겨 두세요. 저장과 제출 방법은 현재 시험 안내를 따르며 다른 CAD 시험의 규칙을 그대로 적용하지 않습니다.

과정 선택에서는 개인 작업과 피드백을 봅니다

공식 수험료는 필기 14,500원, 실기 21,000원입니다. 강의와 프로그램 연습 환경, 교재와 이동비는 별도입니다. 학원 상담에서는 개인별 컴퓨터 사용, 과제 전체 제작 횟수와 도면 피드백, 출력 연습이 포함되는지 확인하세요. 강사 화면을 따라 클릭하는 시간만으로 독립적인 작업이 준비되는 것은 아닙니다.

가상의 비교 예로, 녹화 강의를 여러 번 볼 수 있는 과정과 실제 답안 파일을 점검받는 과정은 제공하는 도움이 다릅니다. 본인이 부족한 것이 조작인지 도면 해석인지 먼저 정리하고 피드백 방식과 질문 가능 시간을 비교하세요. 장시간 화면 작업을 지속할 수 있는 일정과 학습 환경도 실제 과정 선택에 포함합니다.

자격 취득과 채용의 요구를 구분합니다

건축 CAD 관련 공고에서는 자격 우대와 실제 프로그램·도면 경험, 담당 업무를 확인합니다. 시험 대비 도면을 작성한 사실과 실무 설계 프로젝트 참여는 다른 경력입니다. 포트폴리오에 연습 자료를 사용한다면 교육용 작업임을 밝히고 도면 저작권이나 회사 자료의 공개 허용 여부를 확인하세요.

자격증 취득만으로 건축 설계와 모든 현장 업무를 독립적으로 맡을 수 있다고 생각하지 않습니다. 이전 경력의 문서·공정·자재 경험을 사실대로 연결하고 부족한 프로그램이나 실무 작업을 별도로 계획하세요. 어떤 도면 업무를 원하는지 먼저 정하면 시험 공부와 이후 직무 준비를 함께 비교할 수 있습니다.
